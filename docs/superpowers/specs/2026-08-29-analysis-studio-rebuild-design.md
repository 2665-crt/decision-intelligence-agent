# 数据分析决策工作台：全新重建设计

## 产品边界

这是一个新的本地分析工作台，而不是旧版 Agent 的加法重构。用户上传一个 Excel、XLS、CSV 或 DOCX，描述目标后即可获得：可追溯的数据概览与质量检查、基础统计和图表、在可用时间序列上的预测、风险清单、低损害优先的方案比较，以及 Markdown、HTML、Word 报告。

系统不把通用建议伪装为专业结论。医疗、法律、金融、化工和施工安全相关目标会显示人工复核提示；预测只在检测到时间列和数值列、且模型优于朴素基线时给出推荐。

## 新架构

```text
web (React/Vite)
  └─ 上传、目标输入、运行进度、结果与报告下载
api (FastAPI)
  ├─ job_store：每次上传创建独立 Job 和工件目录
  ├─ intake：Excel/CSV/DOCX 解析及摘要
  ├─ analysis_engine：白名单统计、质量、异常、趋势、预测
  ├─ decision_engine：风险、方案、审慎提示
  └─ reporting：Markdown、HTML、DOCX
```

旧版的修订模型、Dify 适配层和双层执行器不再沿用。保留的只是已验证的库能力：pandas/openpyxl/python-docx 读取、statsmodels 预测、Plotly 图表和 python-docx 报告生成。

## 主流程

1. 前端上传单个文件并输入分析目标。
2. API 建立 Job，保存源文件和可读的文件摘要。
3. 用户点击“开始分析”后，API 只调用确定性的白名单分析函数，不执行模型生成的 Python 或 shell。
4. 结果按“数据事实、数据推断、预测、风险、建议、限制”分区展示；图表与三个报告格式均保存到该 Job 的工件目录。
5. 前端可查看图表、风险和方案，并下载报告。

## 验收

- Excel：上传后能看到列、缺失值、统计摘要、数据质量风险、图表和 Word 报告。
- 时间序列：只有明确请求预测且数据条件满足时才预测；报告呈现基线与候选模型误差、区间和限制。
- DOCX：提取文档陈述，输出结构化审阅与报告，不把文档文字当作测量数据。
- 所有文件格式均有错误提示；高风险领域均明确要求人工复核。
- 浏览器可在 Docker Compose 启动后访问工作台。
